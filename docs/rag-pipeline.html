The decisions behind it
Chunking
Sliding window of turns (4, overlap 1), keeping speaker + timestamp — a lone turn has no context; overlap keeps Q/A pairs intact.
Context strategy
Retrieved slice for Q&A (precision); whole transcript for extraction (catch every decision / action item).
Grounding — two layers
prompt cite-or-refuse   +   runtime a verify gate re-checks every answer and self-corrects. A wrong answer is worse than “I don't know”.
